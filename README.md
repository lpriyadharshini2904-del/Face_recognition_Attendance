Face Recognition Attendance System

Project Overview

The Face Recognition Attendance System is a Python-based application designed to automate attendance marking using facial recognition technology. It identifies registered individuals through a camera and records their attendance.

Objectives

Automate the attendance process.
Identify registered individuals using face recognition.
Reduce manual attendance work.
Store attendance records for future reference.
Features
Face detection using a webcam.
Face registration and recognition.
Automatic attendance recording.
Attendance storage using CSV files.
Simple web interface for managing attendance.

Technologies Used

Python
OpenCV
HTML
CSS
JavaScript
CSV for data storage

Project Structure

app.py – Main application
cam.py – Camera operations
register.py – Face registration
trainer.py – Face model training
attendance.py – Attendance management
students.py – Record management
frontend/ – Web interface files
Requirements
Python 3
OpenCV
A webcam
A web browser

How to Run

Clone or download this repository.
Install the required Python packages.
Run the main application using Python.
Register faces and follow the application's instructions to mark attendance.

Privacy Note

Use facial images and attendance records responsibly. Obtain appropriate consent before collecting or storing biometric data.
